Collection Layer (Management API)
GET /api/v1/metrics/all
Scrapes every alive node's port 9090 in parallel.
Picks up: Ray system metrics + vLLM + YOLO + MCP (ray.util.metrics)
10s cache ray.nodes() discovery
GET /api/v1/metrics/apps
Scrapes each app's {route_prefix}/metrics route.
Picks up: SGLang native metrics (proxied via FastAPI /metrics route)
list_applications() per-app scrape
