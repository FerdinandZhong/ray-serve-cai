Backend reference

Backend When selected Workers Our deployment
"uni" world_size == 1 (single GPU) Single process — no inter-process comms ✓ tp=1, gpu_fraction<1 replicas
"ray" Running inside a Ray placement group, OR data_parallel_backend="ray" Ray remote actors — cross-node capable ✓ tp>1 inside Ray Serve deployment
"mp" world_size>1, single node, no Ray placement group OS processes via multiprocessing — same node only Not used (we always run inside Ray)
ValueError Available GPUs < world_size and no explicit backend set — Set distributed_executor_backend="ray" to override
