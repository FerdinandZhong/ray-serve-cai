Location Block Routing

/api/* → ray_serve :5000 Management API (FastAPI)
/docs   /redoc   /openapi.json → ray_serve :5000 Swagger / ReDoc — exact match
/health → ray_serve :5000 liveness probe · access_log off
/dashboard/* → ray_dashboard :8265 WebSocket enabled · 24 h timeout
= / → static HTML index.html served directly by nginx
/*  (catch-all) → ray_serve :5000 /paddleocr/*   /llama3/*   any route_prefix

Streaming settings (every model location)

  • ●proxy_buffering off — tokens flow immediately, not batched
  • ●proxy_read_timeout 300s — default 60 s kills most LLM responses
  • ●Upgrade / Connection headers — SSE & WebSocket passthrough
  • ●keepalive 8 upstream — reuse TCP for high-throughput streams

Config generation

  • ●Templates rendered at startup by start_nginx.py via Jinja2
  • ●Ports / timeouts controlled by env vars — no template edits needed
  • ●client_max_body_size 100M — allows base64-encoded image uploads
  • ●TLS, auth — handled upstream by CML platform, not nginx
